Three equally spaced points. One classical question.

How large can a set of integers be without containing three equally spaced elements? In this mini-course, we approach this classical combinatorial problem by an unexpected route: Fourier analysis.

We will build the necessary Fourier-analytic tools from the ground up, use them to detect hidden structure inside sets of integers, and see how that structure can be amplified until three equally spaced elements are forced to appear.

Prerequisites: Real analysis.
